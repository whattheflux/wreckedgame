# Item art

Drop a PNG here named after the item id and it replaces the placeholder drawing everywhere (hands, inventory, spoils):

`stick.png rollingPin.png fryingPan.png pipe.png humanBone.png knife.png sharpStick.png weightedClub.png torch.png sandSock.png crudeSword.png nailBat.png machete.png poisonDagger.png fireAxe.png`

Square, transparent background, weapon pointing up-right works best (about 256x256). Other items (slingshot, javelin...) can be overridden the same way.
